# Nura device -> what the converter cannot read from the image itself.
#   nura      the Nura/postmarketOS device (deviceinfo_codename), or for a generic SoC image
#             (qcom-sm7150) the phone the zip is for (--device)
#   android   the LineageOS names the zip's assert accepts (ro.product.device / ro.build.product)
#   dtb       generic images only: the DTB (under the image's dtbs/) of this phone; a glob
#   layout    generic images only: the Android boot image header the phone's ABL boots, as
#             hv:PAGE:KERNEL:RAMDISK:SECOND:TAGS:DTB (header version, page size, load addresses),
#             when the image's deviceinfo has none
#   panels    phones sold with different panels, one DTB each: the words that tell them apart, in the
#             DTB's name and in msm_drm.dsi_display0= on the bootloader's command line (--panel)
#   dtbo      clear: the zip zeroes the dtbo partition of the slot it boots from, once boot is written. The ABL lays
#             that partition's overlays (Android's, for its own kernel) over the DTB of every boot image; on a
#             mainline DTB that fails, and the ABL drops to fastboot without a word (OnePlus 6T)
#   mask      units the zip masks on this phone (comma-separated): what the image starts but the phone's kernel cannot
#             serve yet. 81voltd: mainline q6voice has no VoLTE voice session, so a VoLTE call connects and stays
#             silent both ways; without it the modem places calls over 2G/3G, where q6voice carries the audio
#   watchdog  reset: the zip carries two systemd drop-ins (RuntimeWatchdogSec/RebootWatchdogSec=30s, rmtfs
#             TimeoutStopSec=15s): a reboot that hangs in the modem shutdown path is reset by the hardware watchdog
#   modemwake settle: the zip carries a systemd-sleep hook that lets the modem's IPCRTR channel wake the phone
#             (incoming calls in suspend) and takes WLAN down first, whose QMI traffic would abort every suspend
# nura               android                          dtb                                   layout                                       panels          dtbo    mask            watchdog  modemwake
